# Paraguay: Dos Culturas, Dos Idiomas

Proyecto de folclore interactivo sobre la lengua guaraní y la cultura paraguaya.

## 🌍 Descripción

Una web inmersiva que explora la coexistencia única del guaraní y el español en Paraguay, desde la lingüística hasta los rituales, la música y el sincretismo cultural.

## 🎨 Características

- **Diseño responsive** — Funciona en desktop y móvil
- **Interactividad** — Modal de zodiaco, acordeones, CTA flotante
- **Tipografía cuidada** — Fraunces + Work Sans
- **Paleta de colores** — Inspirada en el ñandutí y la tierra paraguaya
- **Videos integrados** — Música tradicional y contemporánea
- **Animaciones suaves** — Scroll, transiciones y efectos

## 🚀 Cómo usar

1. Descarga o clona este repositorio
2. Abre `index.html` en tu navegador
3. Los estilos se cargan desde `css/styles.css`
4. Las imágenes deben estar en la carpeta `img/`
